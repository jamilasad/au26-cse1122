Practice helps, if you do it yourself

Students with 45 or more loop problems solved on the tracksheet: average 18 out of 20. Students with fewer than 35: average 10.3 out of 20. But 5 students with 45 or more got 5 or less in Problem 2. Solving with notes or a friend is not the same as solving alone. Practise alone, from a blank file.

The three most common mistakes

  1. 1

    No final else. When no condition is true, the program prints nothing. Always end an if / else-if chain with else.

  2. 2

    A loop variable with two jobs, or a loop that never ends. Do not read input into the loop counter. Do not use the counter as the value you print. Check three parts in every loop: start, condition and change.

  3. 3

    Saying Yes too early. To check that every value is right, set ok = 1 before the loop. Set ok = 0 when a value is wrong. Print the answer after the loop, not inside it.
