Only the five group-marked tests can be retaken. Those five are the topics people struggle with most. if-else, 2D array, the mid and the final are single attempts — so treat them that way.

How every test runs

25 minutes, one problem

The loop test is the exception: 40 minutes, two problems.

Two shifts

One group sits, finishes and leaves; the next comes in. Seats are spaced and there is no internet.

Two question sets

Sets A and B. The person beside you does not have your problem.

C or C++

Write in either. Submit your code through the form.

A machine marks it

Your code is compiled and run against the samples plus about five hidden cases you never see. I read it afterwards to check the machine.

Test everything first

Compile it, run it, try the samples — and try a case the samples do not cover — before you submit.

Group marking — the five tests

At or below your group's averageYou keep your own mark. Nothing is added and nothing is taken away.
Above your group's averageYou carry part of the gap — 40% your own mark + 60% the group average. The strongest people are responsible for bringing everyone up.
Retaking a group testIn the repair week — the week between tests. We go back over what the class got wrong, and at the end of that same session you sit the test again. You must attend the session to sit it.
What a retake is worthUp to 7 out of 10, never the full 10, because it is a second attempt. Getting it right first time is always worth more.
If you scored 0The retake is compulsory. Do not sit it and the 0 stands.
Absent, told me firstMarked absent — no zero, no penalty. You sit it in the repair week.
Absent without telling meZero, and it counts as a zero in your group's average. You still sit it in the repair week.

How your 10 marks are decided

MarksFull marks ifZero if
Compiles1It builds. Warnings are ignored.Any compile error → the whole problem scores 0
Reads input1Every value read, right order, right specifier, & presentAny value unread, wrong specifier, missing &
Logic2A real method that works for any valid inputHardcoded or fixed output → whole problem scores 0
Sample cases2Both samples exactly rightNeither right — 1 mark if one is right
Hidden cases3All of them passUnder a third pass — 2 if you fail only one, 1 if a third pass
Output format1Spacing, decimals, capitals and newlines match exactlyAny difference at all
Four things score 0 no matter what: it does not compile · the output is hardcoded · your code is identical to someone else's (both of you get 0) · it is not written in C or C++.

There are no marks for effort, neatness, or code that “would work if one line were fixed”. It runs correctly or it does not — the same standard as a job interview.
